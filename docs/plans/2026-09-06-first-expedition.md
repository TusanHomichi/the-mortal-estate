# First expedition

This Planning record owns execution of the owner's instruction to proceed with
the proposed first expedition. The [gameplay baseline](../gameplay-baseline.md)
owns historical fidelity, the [boundary map](../boundary-map.md) owns mutation
seams, and the [surface brief](2026-09-05-first-land-surface.md) owns geography.

## Outcome and sequence

Create a character, arrive at the dock, equip and prepare using town services,
descend through the temple into a bounded first-floor section, survive an
encounter, return with loot, train, and reconnect with state preserved.

1. Recover class, promotion and training contracts with neutral evidence
   bindings; map teaching capabilities to the actual town service roles.
2. Compare carried rules, content, protocol, persistence and client availability.
   Distinguish proven behavior from provisional or conflicting numbers.
3. Connect equipment, banking, lockers, purchases and training through the
   existing authoritative command/observer path. Add creation through rules and
   durable admission, with the server owning identity and transactions.
4. Author the town and verified temple-to-first-floor connection through the
   compiler; add supported encounters and prove the expedition through the real
   client and persistent server.

Death-world play, reconciliation of lineage, full four-floor expansion and the
three deeper floors follow this milestone. This work grants no visual master
acceptance, publication, deployment or Git lifecycle authorization.
