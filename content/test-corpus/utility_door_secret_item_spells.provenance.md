# Utility Door Secret Item Spells Provenance

This is a clean original project Slice BU fixture for local simulation coverage of
utility door control, hidden transition reveal/hide behavior, item identify,
weapon enchantment metadata, item transformation, bounded locate output, and
temporary portal movement between authored rooms.

Slice DZ extends the fixture with one original-provisional bounded Scry-family
cast for clean integrated family-owner proof. The Scry name, observed target,
hint text, and script placement are original project fixture material rather than
recovered source data.

The room layout, spell names, item names, script order, and numeric tuning are
authored for compact deterministic coverage. The fixture uses generic fantasy
vocabulary and original project design intent only.
