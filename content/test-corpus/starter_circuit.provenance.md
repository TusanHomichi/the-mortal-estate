# Starter Circuit Fixture Provenance

`starter_circuit.json` is clean project-authored prototype content.

Evidence basis:

- The tracked first-land translation brief defines route-beat categories for a tiny starter circuit.
- Tracked research conclusions record the clean mechanics already available: schema-v3 terrain, movement budgets, eight-way traversal, inspect context, deterministic monster movement, and engage-then-attack melee readiness.

Clean authorship:

- The map layout is an original 9x6 prototype circuit authored from route-beat functions and movement-budget tuning.
- Terrain names, glyphs, passability, movement costs, actor names, item names, spell names, stats, and script sequence are project-authored fixture values.
- `Thornling` is an original low-threat prototype encounter name and is not a final creature roster decision.
- Neutral terrain labels such as `Arrival Stone`, `Settlement Yard`, `Ward Path`, `Loop Track`, `Briar Scrub`, `Lantern Track`, and `Marker Stone` are prototype fixture vocabulary, not public first-land canon.

Boundary:

- This file does not copy or approximate private first-land geography, route geometry, coordinate sets, private terrain-cost tables, source names, source text, source art, packet schemas, service placement, NPC placement, spawn placement, or ignored runtime data.
- It does not add services, NPCs, doors, stairs, client UI, networking, persistence, reach, ranged, thrown, returning, projectile, retrieval, or leaping-strike mechanics.
