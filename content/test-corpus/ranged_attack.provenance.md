# Ranged Attack Fixture Provenance

`ranged_attack.json` is clean project-authored prototype content.

Evidence basis:

- The tracked ranged attack design defines ranged behavior as a weapon-level
  attack profile with a clean original range value.
- Tracked research boundaries allow common RPG weapon vocabulary and
  independently authored homages while forbidding copied source expression,
  data, maps, names, and packet schemas.

Clean authorship:

- The map layout is an original 7x3 prototype arena authored to prove
  range-limited attack legality.
- Terrain names, glyphs, passability, movement costs, actor names, item names,
  stats, range value, and script sequence are project-authored fixture values.
- `Elm Bow` is a generic clean ranged-weapon fixture name, not a final item
  roster decision.
- `Reedling` is an original low-threat prototype encounter name and is not a
  final creature roster decision.

Boundary:

- This file does not copy or approximate private geography, route geometry,
  coordinate sets, private numeric tables, source names, source text, source
  art, packet schemas, service placement, NPC placement, spawn placement, or
  ignored runtime data.
- It does not add projectile travel, line of sight, cover, ammunition,
  thrown-item landing or retrieval, returning-weapon behavior, leaping-strike
  behavior, services, NPCs, doors, stairs, client UI, networking, or
  persistence.
