# Area Path Terrain Spells Provenance

`area_path_terrain_spells.json` is clean project-authored prototype content for
Slice BT Task 5.

The fixture exists to prove temporary tile-overlay spell behavior in the rules
core and local simulation harness:

- area spell action options and typed area script targets;
- coordinate spell action options and typed coordinate script targets;
- hindered passability and obscured sight overlays;
- coordinate hazard damage, ticking, and expiration;
- darkness and light-style sight overlays in Trace V2 and transcripts.

The room layout, spell names, actor names, stats, coordinates, durations,
movement costs, and script sequence are original project test values. They do not
copy private geography, source coordinate sets, source text, packet schemas, or
quarantined local-reference payloads.
