# Spider Gallery Fixture Provenance

`spider_gallery.json` is clean project-authored prototype content.

Evidence basis:

- The tracked monster encounter archetypes design defines the ambush skulker
  as a named deterministic behavior (hold the starting web hex, spring when
  the player is within two hexes of the web, return when the player breaks
  away).
- Behavior direction was informed by evidence-ladder tier-1 official-era
  manual creature descriptions, consumed as normalized design judgment, not
  copied text or data.
- Tracked research boundaries allow common creature vocabulary and
  independently authored homages while forbidding copied source expression,
  data, maps, names, and packet schemas.

Clean authorship:

- The map layout is an original 8x3 prototype gallery authored to prove the
  web ambush trigger radius and leash behavior.
- Terrain names, glyphs, movement costs, actor names, stats, and the script
  sequence are project-authored fixture values.
- `Giant Spider` is common fantasy vocabulary.

Boundary:

- This file does not copy or approximate private geography, coordinate sets,
  private numeric tables, source names, source text, source art, packet
  schemas, or ignored runtime data.
- It does not add loot, poison, status effects, creature spellcasting,
  services, NPCs, doors, stairs, client UI, networking, or persistence.
