# Thrown Attack Fixture Provenance

`thrown_attack.json` is clean project-authored prototype content.

Evidence basis:

- The tracked thrown item landing and retrieval design defines thrown
  behavior as a weapon-level attack profile with a clean original range
  value, deterministic landing in the defender's hex, and an explicit
  retrieve action.
- Tracked research boundaries allow common RPG weapon vocabulary and
  independently authored homages while forbidding copied source expression,
  data, maps, names, and packet schemas.

Clean authorship:

- The map layout is an original 7x3 prototype arena authored to prove thrown
  landing and retrieval.
- Terrain names, glyphs, passability, movement costs, actor names, item
  names, stats, range value, and script sequence are project-authored fixture
  values.
- `Oak Javelin` is a generic clean thrown-weapon fixture name, not a final
  item roster decision.
- `Burr Hound` is an original low-threat prototype encounter name and is not
  a final creature roster decision.

Boundary:

- This file does not copy or approximate private geography, route geometry,
  coordinate sets, private numeric tables, source names, source text, source
  art, packet schemas, service placement, NPC placement, spawn placement, or
  ignored runtime data.
- It does not add returning weapons, leaping-strike behavior, projectile
  travel, line of sight, cover, ammunition, monster retrieval AI, services,
  NPCs, doors, stairs, client UI, networking, or persistence.
