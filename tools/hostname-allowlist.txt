# Hosts tools/check_hostnames.py accepts in carried files.
#
# One host (or IPv4 literal) per line, lowercase, exact match. '#' starts a
# comment; every entry carries the reason it is legitimate. Reserved names
# (.invalid, .test, .example, .localhost, example.com/net/org), loopback
# addresses, and the RFC 5737 documentation ranges are allowed by rule and never
# need a line here.
#
# This list is deliberately minimal: it holds exactly the strings that appear in
# the tree today, and nothing added in anticipation. An entry earns its place by
# an actual occurrence.
#
# A missing, unreadable, or entry-less copy of this file makes the check
# FAIL CLOSED.
